# UI-тесты и Allure

Для запуска нужны JDK 17, Google Chrome и доступ к тестируемым сайтам.

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
./gradlew clean test
./gradlew allureServe
```

По умолчанию браузер работает без окна. Для запуска с окном:

```bash
./gradlew test -Dselenide.headless=false
```

`allureServe` запускает локальный сервер и открывает отчет в браузере.
Остановить сервер можно сочетанием Ctrl+C. В разделе **Behaviors** тесты
магазина сгруппированы по Epic → Feature → Story. В карточке теста видны
название, важность, владелец, ссылка и дерево шагов. В названиях шагов
параметры заменяются фактическими значениями благодаря AspectJ и флагу
компилятора `-parameters`. На ошибках Selenide прикладывает скриншот и HTML страницы.

Для сохранения отчета после запуска тестов (в том числе неуспешного):

```bash
./gradlew allureReport
```

HTML-отчет: `build/reports/allure-report/allureReport/`.
Исходные результаты: `build/allure-results/`. Каталог `build/` не хранится в Git.
Для передачи отчета можно упаковать каталог HTML-отчета в ZIP или приложить
скриншоты из `allureServe` к Pull Request.

Тестовые пароли генерируются случайно и отображаются в шагах: используйте
только тестовые учетные записи, не реальные пароли.

## Результат проверки 25.10.2026

Сохраненный автономный отчет: [reports/allure/index.html](reports/allure/index.html).
Скачайте файл и откройте в браузере без локального сервера.

Полный прогон: **7 сценариев, 5 прошли, 2 упали**. Регистрация, вход и все
три варианта корзины прошли. В `StudyTest` не найдены кнопка
`.DistributionButtonClose` и ссылка `demoqa.com` в результатах поиска Яндекса.
Эти ошибки существующих сценариев не скрыты и не исключены из запуска.
Критерий полностью зеленого прогона пока не выполнен.

Проверены подставленные параметры шагов, метки и дерево Behaviors в данных
отчета, доступного через запущенный `allureServe`.

При зависании Selenium Manager на сетевой подготовке драйвера можно повторить
запуск с `SE_OFFLINE=true`, **только если совместимый ChromeDriver уже есть
в локальном кеше Selenium**. Эта настройка не отключает сеть в браузере.
